ID Selector

ID selector is used to select the html element using the unique ID of the element.


Class Selector

Class selector is used to select the html element using the class name of the element.


Element Selector

Element Selector is used to select the html element using the html element itself.


Universal Selector

Universal Selector is used to select all the elements.


Attribute Selector

Attribute Selector is used to select the html elements using their attributes.


Group Selector

Group selector is used to select multiple elements at once.


Descandent Selector

Descendant Selector is used to select the all the matching elements even if the element is deeply nested
